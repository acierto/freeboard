# Acceptance evidence

This file maps every acceptance criterion in `docs/reference/FREEBOARD_SPEC.md` ("Acceptance criteria") to its evidence. It is the evidence map for the release gate (task 6.10). Drafted on 2026-11-08.

How to read it:

- Rust tests are named `file::test` under `src-tauri/src/` and run with `cargo test --no-default-features`.
- UI checks are the names in `scripts/ui/check.mjs` (`npm run verify:ui`).
- Unit tests for the interface are in `tests/ui/*.test.ts` (`npm run test:ui`).
- Visual entries are ids in `scripts/visual/matrix.mjs` (`npm run verify:visual`), in light and dark.
- Accessibility is `scripts/a11y/check.mjs` (`npm run verify:a11y`).

Status values:

- **met**: automated evidence exists.
- **met, owner check by hand**: the automated part exists. The part that needs a person (a click-through of the installed app, a native screenshot, a screen reader) is done by the owner outside this change (decision 2026-11-08, "Checks done by a person are out of this change").
- **open: Windows**: only the Windows measurement is missing.
- **gap**: no evidence, or part of the criterion has no evidence. See "Gaps" below.

## Gaps

The review on 2026-11-08 found four gaps (28, 29, 34, 35). Each now has a check or a fix, listed in its row. No gaps are open.

Other notes for the gate:

- **24.** CI's "Safety traceability report" step called a script that does not exist (`scripts/safety-traceability.mjs`) and skipped silently. It now runs `scripts/safety-traceability.sh`, which fails when an invariant has no passing test (fixed 2026-11-08).
- **26.** Only the Windows measurements are open. The AppImage size miss is reported and decided.
- **29.** Risk boxes in item rows start folded, as the prototype does (decision 2026-11-07); on a Risky question card the box starts open, as the spec says.
- **33.** The 120 s limit is a constant (`WORKTREE_TIMEOUT`) with no test of its own; the timeout path is tested with short limits.
- **Accessibility.** The axe check (`npm run verify:a11y`, 160 checks, zero violations) now runs in CI's browser job (added 2026-11-08). The screen-reader session is with the owner.
